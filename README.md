# Evermore

> **A collaborative space to code, compete, and build together.**

Evermore is a real-time developer platform combining **collaborative coding, 1v1 DSA battles, interactive whiteboarding, AI assistance, and cloud-based code execution**.

### 🚧 Currently Building

* 💻 Real-time collaborative code editor
* ⚔️ 1v1 DSA battles with virtual stakes
* 🎨 Collaborative tldraw whiteboard
* 💬 Real-time workspace chat
* ☁️ Secure code execution with Docker + AWS ECS
* 🤖 AI coding assistant
* 🎧 Real-time voice collaboration

### 🛠️ Tech Stack

**Frontend:** React, TypeScript, Monaco, Yjs, Tailwind
**Backend:** Node.js, Express, Socket.io
**Database:** MongoDB
**Cloud:** AWS ECS, ECR, Docker
**AI:** OpenAI API
**Real-time:** Yjs, Socket.io, WebRTC/PeerJS

> **Evermore is currently under active development.**
